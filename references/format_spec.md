# 微信聊天记录导出排版与命名规范 (Format Specification)

> **版本**：v1.1.0 (社群会员版)  
> **适用范围**：`skill-wechat-chat-exporter-member` 输出的所有 Markdown 归档文件。

---

## 1. 文件命名规范（方案 A 精确时间戳）

每个导出的文件按**自然月**聚合，文件名由目标名称、首条文本时间与末条文本时间拼接而成：

```text
<目标名称>_<该月首条消息YYYYMMDDHHMM>-<该月末条消息YYYYMMDDHHMM>.md
```

### 规则要点
1. **时间戳精度**：精确到分钟（12 位数字：`YYYYMMDDHHMM`）。
2. **时间含义**：
   - 前部时间戳：该自然月内导出的**第一条纯文本消息**的时间；
   - 后部时间戳：该自然月内导出的**最后一条纯文本消息**的时间。
3. **空月处理**：若某月份无纯文本消息，直接跳过，**严禁生成空文件**。

### 命名示例
- 群聊示例：`社群答疑交流群_202510121537-202510311112.md`
- 私聊示例：`张三_202606211724-202606212036.md`

---

## 2. 单条消息排版格式（标准三行式）

每条消息严格由以下 3 行组成，消息之间必须保留**一个空行**：

```markdown
发言人名称
YYYY年MM月DD日  H:MM
消息正文内容

```

### 字段格式细节
1. **第一行（发言人）**：纯文本展示，不加粗、不带中括号。
2. **第二行（时间戳）**：
   - 格式：`YYYY年MM月DD日  H:MM`（若小时为个位数，前面补一个空格形成两个空格，如 ` 9:23`；若小时为两位数，保留单个空格，如 `16:04`）。
3. **第三行（正文内容）**：
   - 保留原始换行、标点与链接；
   - 清洗群聊特有的 `wxid_xxxx:\n` 前缀报头。

---

## 3. 发言人显示名称解析优先级

为了确保导出文档的可读性，发言人按以下优先级进行匹配回退：

1. **账号本人**：
   - 识别条件：当前登录账号本人 wxid，或 real_sender_id 为空。
   - 显示为：`CC`（或用户通过 `--self-name` 参数自定义的名称）。
2. **群聊成员 / 好友**：
   - 第一优先：通讯录备注名（`remark`）；
   - 第二优先：微信昵称（`nick_name`）；
   - 第三优先：微信号（`alias`）；
   - 兜底：`wxid` 或 `未知用户`。

---

## 4. 纯文本强过滤原则

1. **保留类型**：仅提取 `local_type = 1`（纯文本消息）。
2. **排除类型**：彻底跳过图片（3）、语音/视频（43）、文件附件（6）、表情包（47）、系统提示（10000）等。
3. **零占位符**：正文中不保留 `[图片]`、`[文件]` 等无有效信息的占位符。
